# Campo Minado — Praça Osório

Aplicativo Android desenvolvido em Kotlin com Jetpack Compose.

## Conceito
Jogo inspirado no Campo Minado, ambientado na Praça Osório. O jogador avança por 10 linhas, escolhendo uma casa em cada linha e evitando os galhos perigosos.

## Estrutura inicial
Este repositório está preparado como base limpa do projeto. A implementação das telas, regras do jogo, persistência e arquitetura será desenvolvida nas próximas etapas.

## Tecnologias
- Kotlin
- Android
- Jetpack Compose
- Material 3
- Navigation Compose
- Room (dependência preparada)

## Abrir o projeto
Abra a pasta do repositório no Android Studio e aguarde a sincronização do Gradle.
